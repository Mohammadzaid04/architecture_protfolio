# Common Components Directory

This directory contains reusable atomic and foundational UI components:

- `Button.tsx` - Accessible button and anchor action component
- `Container.tsx` - Centered page width constraint wrapper
- `Section.tsx` - Semantic `<section>` container with uniform vertical spacing
- `SectionHeading.tsx` - Standardized architectural typography heading
- `Image.tsx` - Performance-aware Cloudinary responsive image wrapper
